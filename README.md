Crypto Data API provides real-time cryptocurrency market data for AI agents and quant traders. It offers live prices, derivatives, funding rates, liquidations, order books, sentiment, on-chain health metrics, and quant regimes across over 190 REST endpoints. The service includes gasless USDC payments via the x402 protocol, one‑call onboarding, and a free tier with optional paid plans in USDC. Designed for AI integration, it supports high‑frequency streaming and comprehensive data coverage.

**Areas:** Company · Crypto · Finance · Data · Real-time · Market-Data

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for cryptodataapi-com: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
